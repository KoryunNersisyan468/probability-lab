# 🎮 Probability Games

## 🚪 Three Doors — Monty Hall Problem

The classic Monty Hall probability problem.

There are three doors:

- 🚪 One door contains a prize
- 🚪 Two doors contain nothing

The player chooses a door. The host then opens another door that does not contain the prize.

The player can:

- Stay with the original choice
- Switch to the remaining door

### Probability

Stay:

`text
1/3 ≈ 33.3%

Switch:

2/3 ≈ 66.7%

The game allows users to test this result experimentally instead of simply accepting the mathematical explanation.

🔐 Password Challenge

An educational simulation showing how the number of possible combinations affects probability.

For example:

4-digit PIN

10⁴ = 10,000 possible combinations

Probability of randomly guessing the correct PIN in one attempt:

1 / 10,000

6-digit PIN

10⁶ = 1,000,000 possible combinations

The challenge demonstrates how increasing the number of possible combinations dramatically decreases the probability of a correct random guess.

> ⚠️ This is an educational probability simulation. It does not perform real password or credential attacks.

🔬 Example

Suppose a coin is flipped 10 times.

Theoretical probability:

Heads = 50%

Experimental result:

Heads = 7 / 10
       = 70%

The result is different from 50%, but this does not mean the theory is wrong.

After many more experiments:

10 flips       → 70%
100 flips      → 54%
1,000 flips    → 50.8%
10,000 flips   → 50.1%

The experiment demonstrates how larger sample sizes tend to produce results closer to the theoretical probability.
